# Ejercicio-5---Modelo-Entidad-Relaci-n-de-un-Sistema-de-Gesti-n-Acad-mica
Descripción Este ejercicio consiste en diseñar un modelo Entidad-Relación (DER) para un sistema de gestión académica. El modelo permite administrar alumnos, profesores, asignaturas, comisiones, carreras y planes de estudio, representando las relaciones entre estos elementos educativos.
